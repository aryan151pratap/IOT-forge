// devices/{device_id} hhtp requests with websocket between esp32

React makes HTTP request.
FastAPI creates a unique request_id.
FastAPI sends that request_id to the ESP32 through the existing WebSocket.
ESP32 sends the response back with the same request_id.
Your single WebSocket receive loop sees the response.
It finds the matching request_id and resolves the waiting HTTP request.
FastAPI returns that ESP32 response to React.
